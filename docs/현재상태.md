**'추천도서'가 아니라 '적합도서'다** — 외부 전문가가 좋다고 고른 책이 아니라 이
독자에게 맞는 책을 고른다. 비독자에게 부적합한 추천은 오히려 독서 행동을 낮춘다
(이순영 외, 2024).

**처방 B (약점 훈련 방향) — ✅ 동작.** 12셀에서 정답률 0.70 미만 셀을 뽑아
계층적 우선순위(사실적 → 추론 → 비판)로 훈련 셀을 정한다.

**환경 조정 처방 — ⚠️ 항상 스킵** (`6b75822`, STR-92)

```python
ENV_PERCENTILES: Dict[GradeGroup, tuple] = {}     # environment.py:35
```

**빈 채로 뒀다.** 개발용 임시값을 넣으면 근거 없는 `environment_level` 이 진짜
값처럼 DB에 남고, 나중에 파일럿 데이터와 섞였을 때 구분할 방법이 없다.

건너뛴 사유를 두 가지로 구분해 남긴다 — `no_score`(보호자 미응답) /
`no_thresholds`(경계값 미확정). **'데이터가 없는 것'과 '아직 안 켜진 것'은 다르다.**

파일럿 후 이 표만 채우면 코드 변경 없이 켜진다.

**처방군은 환경으로 바뀌지 않는다** — 진단 매트릭스는 유창성 × 독해 2축이고
환경은 3번째 축이 아니다. 환경은 "무엇을 처방할지"가 아니라 "어떻게 전달할지"만
바꾼다(문준석 확정, STR-92).

## 3. 이 프로젝트가 반복해 내린 결정 — 관통 원칙

개별 커밋을 하나씩 보면 흩어져 보이지만, 같은 성격의 판단이 계속 나온다.
**새 기능을 판단할 때 이 네 가지를 기준으로 보면 된다.**

### 3-1. 측정하지 않은 것을 측정한 것처럼 만들지 않는다

| 자리 | 없을 때 어떻게 하나 |
|---|---|
| 환경 경계값 | `ENV_PERCENTILES = {}` → 판정 스킵, 사유 기록 |
| 음독 채점 | `unscorable` → A1·A2 `null`. 0·1.0 금지 |
| 메타인지 | 예측 미수집 → 세 컬럼 `null`. 항목 미표시 |
| VAD | 런타임 없으면 `available=false`, 화면 측정 시간 사용 |
| 법정 기재 | 빈 문자열 유지. `publishable=false` |
| 보관기간 | 종료일 없으면 `None`. 날짜를 지어내지 않음 |

**왜** — 없는 값을 0이나 기본값으로 채우면 '재지 않았다'가 '이런 값이 나왔다'로
바뀐다. 그 순간 근거 없는 판정이 학생·보호자에게 전달된다.

오늘 고친 메타인지가 정확히 이 원칙이 깨져 있던 자리였다.

### 3-2. 과제를 수행하지 않고도 통과하는 측정을 막는다

| 결함 | 통과율 | 고친 커밋 |
|---|---|---|
| 정답 위치 편향 | 0.698 | `35b98f6` |
| 선지 길이 편향 | 0.742 | `0d12e51` |
| 음독: 같은 길이면 만점 | 1.000 | `1828799` |
| 묵독: 버튼만 눌러도 '유창성 높음' | — | `8bd4748` |
| 정확도 분모를 클라이언트가 전송 | — | `1828799` |

**왜** — 이 프로젝트의 목적은 순위를 매기는 것이 아니라 **"이 정도 수준의
학생이면 이런 책을 읽으면 좋겠다"** 를 알려주는 것이다. 측정이 실력을 반영하지
않으면 추천이 통째로 틀어진다.

### 3-3. 기술 실패를 학생의 능력 부족으로 읽지 않는다

- `quality_gate` 를 채점 성립 여부와 분리 — "STT가 못 알아들음" ≠ "아이가 못 읽음"
- 60초 타임아웃을 접두부 정렬로 처리(`6afd16f`) — "시간이 모자람" ≠ "마이크 실패"
- 계획된 묵독과 음독 실패를 구분(계약 상황 ②③④) — **아직 미구현**, 테이블 신설과 묶임

이것은 문준석의 8패키지 L0에도 **프로젝트 상위 목적**으로 적혀 있다.

### 3-4. 아동 음성·개인정보를 국외로 내보내지 않는다

- 서울 리전 이전(`1e53d27`)
- VAD는 로컬 2MB ONNX — 음성이 서버 밖으로 나가지 않음
- 음성 미보관 설계 — `audio_stored` 기본 false
- LLM에는 고정 응원 문구만. 이름·점수·식별자 없음
- 실명 미수집. 식별코드(`elem5-017`)만 쓰고 대조표는 시스템 외부
- 아동 음성 데이터를 **OneDrive 동기화 폴더에 두지 않는다** — Microsoft로의
  국외이전이 되어 서울 리전 결정과 모순된다
