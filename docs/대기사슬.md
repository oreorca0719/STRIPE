## 1. 가장 큰 사슬 — 파일럿

```
STR-79  파일럿 설계 (대상·인원·기간·응시환경)      문준석 · 55일 경과
   │
   ├──→ PILOT_END_ON ──→ STR-86 법정 필수 8건 ──→ 방침 게시
   │                         PM 7건 · 문준석 1건        │
   │                                                    ↓
   │                                              법률 자문  ← STR-130 ③
   │                                                    ↓
   └──────────────────────────────────────────→  파일럿 착수
                                                        ↓
                                              실제 학생 데이터
                                                        ↓
              ┌──────────────┬──────────────┬───────────┴──────┐
              ↓              ↓              ↓                  ↓
        STR-15 임계값    ENV_PERCENTILES  STR-106 난도라벨  STR-112 소요시간
        유창성 P33/P67   환경 조정 처방    (권고: 파일럿 후)  동의서 '20~30분'
        독해 경계
        A4 타당성 범위
```

### 이 사슬에 걸려 있는 것들

| 지금 상태 | 파일럿이 끝나야 |
|---|---|
| 유창성 경계값 `(2.5, 3.8)` — 시연용 | 실제 분포의 P33/P67 |
| 독해 경계값 `(0.55, 0.80)` — 시연용 | 실제 분포 |
| `ENV_PERCENTILES = {}` — 환경 처방 항상 스킵 | 표만 채우면 코드 변경 없이 켜짐 |
| A4 타당성 `0.3 ~ 15.0` — 추정치 | 실제 학생 속도 분포 |
| 동의서 "20~30분" — 근거 없음 | 실측값 |
| 난도 라벨 — 통사 복잡도만 가름 | Betts 분포로 유효성 판단 |

**리포트에 수치를 직접 노출하지 않는 것**도 이 때문이다. 근거 없는 숫자를
학생·보호자에게 보이지 않는다.

### ⚠️ 여기에 순환이 있다

문준석의 STR-79 답변 원문이다(2026-07-31).

> "대상 학년·인원·기간·모집 경로·응시 환경·응시 횟수는 **MVP1 완결 시점에
> 확정하겠습니다.** … 파일럿 설계 자체가 MVP1 범위 안의 일이고, **MVP1이
> 완결돼야** 실제로 무엇을 어떤 상태로 돌릴지가 정해집니다."

그런데 MVP1의 남은 항목이 파일럿 설계를 필요로 한다.

```
STR-112  소요시간 실측    →  실제 아동 응시 필요    →  파일럿
STR-101  토큰 수명 결정    →  공용 기기인가?        →  파일럿 설계
STR-90   계정 발급 인원     →  몇 명인가?           →  파일럿 설계
STR-86   보관기간 기산점    →  파일럿 종료일        →  파일럿 설계
```

**서로가 서로를 기다린다.** 이 고리는 안에서 풀리지 않는다.

**끊는 방법** — 파일럿 종료일을 **잠정으로라도** 정하면 STR-86의 8건이 채워지고,
그러면 방침 게시 → 법률 자문 경로가 열린다. 나머지는 그 뒤에 따라온다.
**PM 결정 사항이다.**

## 2. 음독 사슬

```
STR-132 확인 요청 6건 (2026-09-24 올림, 회신 전)
   │  ① oral_reading_results 신설 여부
   │  ② 모호성 2축 판정 기준      ← 정의가 없어 구현 불가
   │  ③ prefix_global 정렬 규칙
   │  ④ 감독자 입력 경로의 위치   ← 계약에 개념 자체가 없음
   │  ⑤ 처리 순서 ③④ 확인
   │  ⑥ scoring_rule_version 형식
   ↓
oral_reading_results 신설 + 상황②③④ 분리 (Package #3·#5)
   ↓
STR-82 녹음 화면 · STR-83 분석기 완성
   ↓
D-1 활성화 — 3요건 전부 충족 시에만
   (i) 아동 음성 STT 파일럿 통과    ← 파일럿 사슬
   (ii) 법적 검토 완료              ← 파일럿 사슬
   (iii) 문준석 별도 승인
```

**②와 ④가 ①을 막는다.** 모호성 2축은 그 테이블의 컬럼인데 **무엇을 모호하다고
볼지가 계약에 없다.** 컬럼을 만들어도 채울 수 없다.

**음독은 파일럿 사슬과도 묶여 있다.** 3요건 중 둘이 파일럿을 전제한다.
