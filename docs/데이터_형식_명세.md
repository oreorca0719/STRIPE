# 데이터 형식 명세

> **이 문서는 자동 생성된다. 손으로 고치지 않는다.**
> 정본은 `backend/app/contracts/` 의 코드다. 형식을 바꾼 뒤
> `python -m app.contracts.spec` 로 다시 만든다. 코드와 다르면 테스트가 실패한다.

공통 규칙 (모든 형식)

| 규칙 | 어기면 |
|---|---|
| 형식에 없는 키 | 거부 |
| 숫자 칸에 문자열·참/거짓 (`"5"`, `True`) | 거부 — 자동 변환하지 않는다 |
| 만든 뒤 값 고치기 | 거부 — 바꾸려면 새로 만든다 |
| JSONB 칸에 dict 저장 | 거부 — 형식 객체만 저장한다 |
| DB 에서 형식과 다른 행을 읽기 | 읽는 순간 오류 |

`null` 은 **측정 안 함·해당 없음**이다. 0 과 다르다. 원칙은 `docs/데이터_형식_원칙.md`.

## 측정 → 채점·적응형·판정 라인의 형식

```
생산자  frontend DiagnosisView (묵독 기록·문항 응답) · services/diagnosis/scoring.py
        · adaptive.py
소비자  api/endpoints/diagnosis.py · services/diagnosis/attention.py · pipeline.py
저장    fluency_results.reading_time_ms · away_events · a4_syllable_per_sec
        · comprehension_results · diagnosis_rounds.text_repeated
```

### AwayEvent

읽는 동안 화면이 가려지거나 돌아온 순간.

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `type` | `AwayEventType` | 필수 | hidden=가려짐, visible=돌아옴 |
| `at_ms` | 정수 ≥0 | 필수 | 읽기 시작 버튼부터 경과한 ms |

### AwayEvents

한 번 읽는 동안의 이탈 이벤트 **원본**, 시간순.

같은 종류가 연달아 올 수 있다(화면 쪽 두 감지 경로가 겹친다). 정리는
집계할 때 한다 — 원본은 받은 그대로 남긴다(원칙 4).

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `events` | [AwayEvent](#awayevent) 목록 | 필수 | 시간순. 없으면 빈 목록 |

### SilentReadingSubmit

묵독 한 번의 측정 결과.

읽기 시간은 **'읽기 시작'과 '다 읽었어' 버튼 사이의 실제 시각 차이(ms)**다.
예전에는 1초마다 1씩 오르는 화면 타이머를 보냈다. 1초 단위라 거칠고,
탭이 가려지면 브라우저가 타이머를 늦춰 시간이 짧게 잡혔다(→ A4 부풀림).

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `session_id` | 정수 | 필수 | diagnosis_sessions.id |
| `round_id` | 정수 | 필수 | diagnosis_rounds.id — 어느 지문을 읽었나 |
| `reading_time_ms` | 정수 ≥0 | 필수 | 두 버튼 사이의 실제 시각 차이(ms) |
| `away_events` | [AwayEvent](#awayevent) 목록 | 필수 | 읽는 동안의 이탈 이벤트, 시간순 |

### AwaySpan

나갔다가 돌아오기까지 한 구간.

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `from_ms` | 정수 ≥0 | 필수 | 나간 시각 (읽기 시작 후 ms) |
| `to_ms` | 정수 ≥0 | 필수 | 돌아온 시각. 돌아오지 않았으면 읽기 종료 시각 |
| `returned` | 참/거짓 | 필수 | 읽기가 끝나기 전에 돌아왔나 |

계산값 (저장하지 않는다): `duration_ms`

### AttentionSummary

이탈 원본 + 읽기 시간에서 계산한 집계. 판정에는 쓰지 않는다(보정 방식 미정).

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `reading_time_ms` | 정수 ≥0 | 필수 | 읽기 시간(ms). 0 이면 비율을 낼 수 없어 거부 |
| `spans` | [AwaySpan](#awayspan) 목록 | 필수 | 의미 있는 이탈 구간 (짧은 흔들림 제외) |

계산값 (저장하지 않는다): `away_total_ms` · `away_ratio` · `longest_away_ms` · `reading_time_excluding_away_ms`

### AnswerSubmit

문항 하나에 고른 답. 선지 수 이내인지·그 회차 지문의 문항인지는 서버가 DB 로 확인한다.

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `round_id` | 정수 | 필수 | diagnosis_rounds.id |
| `question_id` | 정수 | 필수 | questions.id — 그 회차 지문의 문항이어야 한다 |
| `student_answer` | 정수 ≥1 | 필수 | 고른 선지 번호, 1부터 — 선지 번호 — 개수·시간이 아닌 순번 |
| `response_time_ms` | 정수 ≥0 또는 null | 생략 시 null | 문항을 보고 고르기까지 ms. 안 쟀으면 null |

### AreaTally

한 회차에서 한 영역의 정답 수·문항 수.

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `area` | `TargetArea` | 필수 | 독해 영역 |
| `correct_count` | 정수 ≥0 | 필수 | 맞힌 문항 수 |
| `question_count` | 정수 ≥0 | 필수 | 푼 문항 수. 0 이면 이 영역은 측정 안 함 |

계산값 (저장하지 않는다): `accuracy`

### RoundAggregate

한 회차의 채점 집계 — 영역 3칸의 원본 수. 정답률·Betts 는 여기서 계산한다.

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `areas` | [AreaTally](#areatally) 목록 | 필수 | A5·A6·A7 순서 고정, 3칸 |

계산값 (저장하지 않는다): `correct_count` · `question_count` · `accuracy`

### AreaTallyView

화면에 보내는 영역 집계 — 정답률을 서버가 계산해 붙였다.

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `area` | `TargetArea` | 필수 | 독해 영역 |
| `correct_count` | 정수 ≥0 | 필수 | 맞힌 문항 수 |
| `question_count` | 정수 ≥0 | 필수 | 푼 문항 수 |
| `accuracy` | 실수 0~1 또는 null | 생략 시 null | 정답률 0~1. 문항이 없으면 null |

### RoundAggregateView

화면에 보내는 회차 집계.

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `correct_count` | 정수 ≥0 | 필수 | 맞힌 문항 수 |
| `question_count` | 정수 ≥0 | 필수 | 푼 문항 수 |
| `accuracy` | 실수 0~1 또는 null | 생략 시 null | 정답률 0~1. 문항이 없으면 null |
| `betts_level` | `BettsLevel` 또는 null | 생략 시 null | 정답률로 정한 Betts 수준. 문항이 없으면 null |
| `areas` | [AreaTallyView](#areatallyview) 목록 | 필수 | A5·A6·A7 순서 |

### AdaptiveDecision

방금 끝난 회차 뒤의 행동.

계속이면 다음 난도·장르가 있고, 종료면 영점 난도와 신뢰도가 있다.
한쪽의 칸이 다른 쪽에 섞이면 거부한다.

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `action` | `AdaptiveAction` | 필수 | continue=다음 회차, stop=종료 |
| `status` | `DiagSessionStatus` | 필수 | 이 판단 뒤 세션 상태 |
| `anchor_difficulty` | `Difficulty` 또는 null | 생략 시 null | 종료 시 영점 난도 |
| `reliability_flag` | `ReliabilityFlag` 또는 null | 생략 시 null | 종료 시 측정 신뢰도 |
| `next_difficulty` | `Difficulty` 또는 null | 생략 시 null | 계속 시 다음 난도 |
| `next_genre` | `TextGenre` 또는 null | 생략 시 null | 계속 시 다음 장르 |

## 판정 → 처방·리포트 라인의 형식

### Disclaimers

면책 코드의 **집합**. 순서에 뜻이 없고 중복이 없다.

코드가 없으면 빈 목록이다. null 이 아니다 — null 은 "판정하지 않음"이다.

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `codes` | `DisclaimerCode` 목록 | 필수 | 면책 코드. 중복 없이 enum 정의 순서 |

### CellResponse

약점 프로필을 만들 문항 응답 — 어느 영역·어느 장르 지문의 문항을 맞혔는가.

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `target_area` | `TargetArea` | 필수 | 문항이 재는 독해 영역 |
| `genre` | `TextGenre` | 필수 | 그 문항이 딸린 지문의 장르 |
| `is_correct` | 참/거짓 | 필수 | 정답 여부 |

### WeaknessCell

영역 × 장르 한 칸. 정답 수와 문항 수를 남긴다.

정답률만 남기면 2문항 중 1개와 10문항 중 5개가 같은 0.5 가 된다.
정답률은 원본(두 수)에서 계산하는 값이라 저장하지 않는다(원칙 4).

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `area` | `TargetArea` | 필수 | 독해 영역 |
| `genre` | `TextGenre` | 필수 | 지문 장르 |
| `correct_count` | 정수 ≥0 | 필수 | 맞힌 문항 수. 문항 수 이하 |
| `question_count` | 정수 ≥0 | 필수 | 푼 문항 수. 0 이면 이 칸은 측정 안 함 |

계산값 (저장하지 않는다): `accuracy`

### WeaknessProfile

3영역 × 2장르 = **6칸 고정**, CELL_ORDER 순서.

DB 칸 이름은 명세를 따라 `weakness_profile_12` 지만 실제는 6칸이다.
12 가 무엇의 곱인지는 기획 확인 대기(docs/모듈간_데이터_확정필요.md 2-1).

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `cells` | [WeaknessCell](#weaknesscell) 목록 | 필수 | 6칸. A5·A6·A7 × 이야기글·설명글 순서 고정 |

계산값 (저장하지 않는다): `correct_count` · `question_count` · `overall_accuracy`

### FluencyJudgment

유창성 판정. 값의 단위가 경우마다 달라서 값 칸과 단위 칸을 짝으로 둔다(원칙 1).

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `fluency_level` | `Level3` | 필수 | 유창성 3단 수준. 측정 불가일 때도 배치를 위해 mid |
| `fluency_source` | `FluencySource` | 필수 | 어느 측정에서 왔나. 측정 불가면 unavailable |
| `fluency_valid` | 참/거짓 | 필수 | 판정에 쓸 수 있는 값인가 |
| `fluency_value` | 실수 또는 null | 생략 시 null | 단위는 짝 칸 fluency_value_unit |
| `fluency_value_unit` | `FluencyUnit` | 필수 | 값의 단위. SPS=음절/초(묵독), CWPM=음절/분(음독), 값 없으면 none |
| `reliability_flag` | `ReliabilityFlag` | 필수 | 유창성 측정의 신뢰도 |
| `disclaimers` | [Disclaimers](#disclaimers) | 필수 | 유창성에서 나온 면책 코드 |

### ComprehensionJudgment

독해 판정. 정답 수·정답률은 프로필에서 계산한다 — 두 번 세지 않는다(원칙 5).

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `comprehension_level` | `Level3` | 필수 | 독해 3단 수준. 문항이 없으면 배치를 위해 mid |
| `profile` | [WeaknessProfile](#weaknessprofile) | 필수 | 영역×장르 6칸의 정답 수·문항 수 |
| `reliability_flag` | `ReliabilityFlag` | 필수 | 문항이 하나도 없으면 unstable |

계산값 (저장하지 않는다): `overall_accuracy`

### MatrixPlacement

유창성 × 독해 9칸 배치. 위치 문자열은 두 수준에서 만든다(원칙 5).

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `fluency_level` | `Level3` | 필수 | 행 — 유창성 수준 |
| `comprehension_level` | `Level3` | 필수 | 열 — 독해 수준 |
| `label_5` | `Label5` | 필수 | 9칸에서 정해지는 5단 라벨 |
| `prescription_group` | `PrescriptionGroup` | 필수 | 9칸에서 정해지는 처방군 |

계산값 (저장하지 않는다): `matrix_position`

### MetacognitionResult

자기 예측(D-2)과 실제의 차이. 10문항 기준으로 환산한 정답 수로 비교한다.

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `metacognition` | `Metacognition` | 필수 | 예측이 실제보다 높은가·낮은가·맞는가 |
| `actual_correct_count_of_10` | 정수 ≥0 | 필수 | 실제 정답률을 10문항 기준으로 환산한 정답 수 (반올림) |
| `gap_count` | 정수 | 필수 | 예측 − 실제, 문항 수 차이. 음수면 과소평가 쪽 |

|---|---|---|---|
| `area` | `TargetArea` | 필수 | 독해 영역 |
| `genre` | `TextGenre` | 필수 | 지문 장르 |
| `correct_count` | 정수 ≥0 | 필수 | 맞힌 문항 수 |
| `question_count` | 정수 ≥0 | 필수 | 푼 문항 수 |
| `accuracy` | 실수 0~1 또는 null | 생략 시 null | 정답률 0~1. 문항이 없던 칸은 null |

### WeaknessProfileView

|---|---|---|---|
| `cells` | [WeaknessCellView](#weaknesscellview) 목록 | 필수 | 6칸, 저장 형식과 같은 순서 |

### RecommendedTexts

추천 지문의 **참조 목록**, 우선순위 순서.

예전에는 제목·난도·장르까지 복사해 저장했다. 그러면 같은 사실(지문 제목)이
texts 와 여기 두 곳에 생긴다(원칙 5). 이제 id 만 남기고, 화면에 보여 줄
때 리포트가 지문 테이블에서 읽는다. 보여 준 그대로의 사본은 리포트에 남는다.

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `text_ids` | 정수 목록 | 필수 | texts.id. 앞이 우선순위 높음, 중복 없음, 최대 5 |

### TrainingTarget

약점 훈련 대상 한 칸.

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `area` | `TargetArea` | 필수 | 훈련할 독해 영역 |
| `genre` | `TextGenre` | 필수 | 훈련할 지문 장르 |

### TrainingPlan

약점 훈련 대상, 우선순위 순서, 최대 2칸.

예전에는 정답률과 활동 안내 문장까지 담았다. 정답률은 판정의 약점
프로필에 이미 있고(원칙 5), 안내 문장은 영역에서 정해지는 표시용
문구다. 이제 대상만 남긴다. 대상이 없으면 훈련이 필요 없다는 뜻이다.

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `targets` | [TrainingTarget](#trainingtarget) 목록 | 필수 | 우선순위 순, 최대 2칸, 중복 없음. 비면 훈련 불필요 |

계산값 (저장하지 않는다): `needed`

### EnvironmentAdjustment

가정환경 하위일 때 추천을 조절하는 값 (문준석 STR-92).

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `success_emphasis` | 참/거짓 | 필수 | 완독 성공 경험을 강조할지 |
| `syllable_limit` | 정수 ≥0 또는 null | 생략 시 null | 추천 지문 분량 상한(음절). null 이면 제한 없음. 아직 소비처 없음 |

### EnvironmentResult

가정환경 판정. 판정했으면 수준·조절값이 있고, 건너뛰었으면 사유가 있다.

수준이 null 인 이유를 남긴다 — 보호자가 답하지 않은 것과 경계값이 없는
것은 다른 상황이다. 보호자 안내 문구는 수준에서 정해지므로 담지 않는다
(environment.guidance_tone 으로 만든다).

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `environment_level` | `Level3` 또는 null | 생략 시 null | 가정환경 3단 수준. 건너뛰었으면 null |
| `environment_adjustment` | [EnvironmentAdjustment](#environmentadjustment) 또는 null | 생략 시 null | 수준이 있을 때만 있다 |
| `skipped_reason` | `EnvironmentSkipReason` 또는 null | 생략 시 null | 건너뛰었을 때만 있다 |

계산값 (저장하지 않는다): `applied`

## 리포트 → 학생 화면 라인의 형식

```
생산자  services/diagnosis/report.py
소비자  frontend ResultView · AdminDiagnosesView
저장    reports.report_content · reports.disclaimer_flags · reports.template_ids_used
[이 라인의 성격 — 표시용 문서]
리포트는 판정·처방에서 **만들어 낸 결과물**이고, 학생이 본 그대로 남아야 한다.
그래서 판정 쪽과 달리 정답률·제목 같은 계산값과 표시 문구를 그대로 담는다.
원본은 판정·처방에 있고, 이 문서는 그 원본에서 한 번 만든 사본이다(원칙 4).
```

### RecommendedPreview

추천 지문 미리보기 한 편 — 리포트를 만든 시점의 제목 사본.

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `text_id` | 정수 | 필수 | texts.id |
| `title` | 문장 | 필수 | 지문 제목 — 리포트 생성 시점의 사본 |
| `genre` | `TextGenre` | 필수 | 지문 장르 |
| `difficulty` | `Difficulty` | 필수 | 지문 난도 |

### ReportSummary

1층 — 요약.

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `label` | 문장 | 필수 | 학생 친화 라벨 문구 (report.STUDENT_LABEL) |
| `label_code` | `Label5` | 필수 | 라벨 문구의 원래 코드 |
| `strengths` | 문장 목록 | 필수 | 강점 문구 — '이야기글에서 사실 찾기' 형태 |
| `encouragement` | 문장 | 필수 | 응원 문구 — 템플릿 또는 폴백, LLM 다듬기 가능 |
| `recommended_preview` | [RecommendedPreview](#recommendedpreview) 목록 | 필수 | 처방 추천 순서대로 최대 3편 |

### FluencyView

유창성 — 판정 값을 그대로 옮긴다(변조 금지 §6).

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `level` | `Level3` | 필수 | 유창성 3단 수준 |
| `valid` | 참/거짓 | 필수 | 판정에 쓴 값인가. false 면 화면이 수치를 보여주지 않는다 |
| `value` | 실수 또는 null | 생략 시 null | 단위는 짝 칸 value_unit |
| `value_unit` | `FluencyUnit` | 필수 | SPS=음절/초, CWPM=음절/분, 값 없으면 none |

### AreaView

영역 × 장르 한 칸의 정답률. 문항이 없던 칸은 null(측정 안 함).

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `area` | `TargetArea` | 필수 | 독해 영역 |
| `genre` | `TextGenre` | 필수 | 지문 장르 |
| `accuracy` | 실수 0~1 또는 null | 생략 시 null | 정답률 0~1. 문항이 없던 칸은 null |

### ComprehensionView

독해 — 판정 값을 그대로 옮긴다.

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `level` | `Level3` | 필수 | 독해 3단 수준 |
| `overall_accuracy` | 실수 0~1 또는 null | 생략 시 null | 전체 정답률 0~1. 문항이 없으면 null |
| `areas` | [AreaView](#areaview) 목록 | 필수 | 6칸, 약점 프로필과 같은 순서 |

### TrainingView

약점 훈련 안내 한 칸 — 처방의 훈련 대상에 안내 문장을 붙였다.

| 칸 | 형식 | 필수 | 설명 |
|---|---|---|---|

| `genre` | `TextGenre` | 필수 | 훈련할 지문 장르 |
| `activity` | 문장 | 필수 | 활동 안내 문장 (prescription._ACTIVITY) |

### ReportDetail

| 칸 | 형식 | 필수 | 설명 |
