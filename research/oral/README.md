# 음독 연구 스크립트

파일럿 이전 단계의 탐색용이다. 배포에 들어가지 않으며, 백엔드 venv 와
분리된 환경에서 돌린다(ML 패키지가 배포 이미지를 무겁게 만들지 않도록).

    python -m venv ~/Desktop/stt-lab/.venv
    ~/Desktop/stt-lab/.venv/Scripts/pip install onnxruntime soundfile numpy

silero-vad ONNX(2MB)는 stt-lab 아래 둔다. 데이터셋도 리포 밖에 둔다 —
아동 음성이고 재배포가 금지돼 있다.

## 스크립트

| 파일 | 용도 |
|---|---|
| `vad.py` | 발화 구간 검출. 백엔드 `app/services/stt/vad.py` 의 원본 |
| `validate_vad.py` | VAD 정확도 검증 시도 |
| `inspect_source.py` | 원천 데이터 구조 확인 |

## AI Hub 「한국어 아동 음성」 검증 결과 — 2026-08-09

**이 데이터셋으로는 음독 자동화를 정량 검증할 수 없다.** 정답으로 쓰려던
필드 세 가지가 모두 정답이 아니었다.

| 필드 | 기대 | 실제 |
|---|---|---|
| `ErrorTagged` | 미스큐 정답 | **전건 `N/A`** (215,199건) |
| `LabelText` | 실제 발화 전사 | **대본**. 같은 문장을 최대 25명이 읽었는데 문자열이 완전히 동일 |
| `SpeechStart/End` | 발화 구간 정답 | **파일 경계 관례**. `SpeechEnd = 파일길이 − 0.1초`가 97% |

그래서 VAD 검증에서 나온 "구간 오차 34.6%"는 VAD 오차가 아니라 파일 앞뒤
무음의 양이다. VAD 는 실제 발화 구간을 제대로 잡고 있었다.

**남은 쓸모**: 학년별 읽기 속도 분포(대본 음절 수 ÷ 파일 길이). 앞뒤 무음이
포함돼 실제보다 느리게 나오므로 보수적인 값이다.

| 학년 | P33 | 중앙 | P67 |
|---|---:|---:|---:|
| 초4 | 3.27 | 3.54 | 3.82 |
| 초5 | 3.45 | 3.76 | 4.09 |
| 초6 | 3.75 | 4.01 | 4.30 |

*(음절/초, 정형 낭독 21.5만 발화·화자 716명)*

**검증은 파일럿으로 미룬다.** 감독자가 잰 시간과 VAD 시간을 대조하면 실제
운영 조건에서 답이 나온다. 별도 비용이 들지 않는다.
